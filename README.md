# PEF – Programación Eficiente

Este repositorio contiene ejercicios, parciales, prácticos y el proyecto final realizados durante la materia **Programación Eficiente** en la Universidad Blas Pascal.

---

## Contenido del repositorio

- [`proyecto-final/`](proyecto-final/)
  **Proyecto final:** sistema de análisis en tiempo real de comentarios de YouTube (hashtags, tendencias y sentimiento con IA). Tiene su propio [README](proyecto-final/README.md) con la arquitectura, las decisiones de optimización y cómo correrlo.

- `Parciales/`
  Resoluciones de los exámenes parciales.

- `practicos/`
  Trabajos prácticos de la materia:
  - `Practico1-memoizacion`: memoización para optimizar algoritmos recursivos.
  - `Practico2-dataStruct`: elección de estructuras de datos.
  - `Practico3-Optimizacion`: optimización de código.
  - `Practico4-Batching`: procesamiento por lotes.
  - `Practico5-PEP8`: buenas prácticas y PEP 8.
  - `Practico6-Profiling&Testing`: profiling y testing.

---

## Uso del repositorio

Se requiere Python 3 (los ejercicios se hicieron con 3.13; el proyecto final usa 3.12).

```bash
git clone https://github.com/galiasmu/PEF.git
cd PEF
```
